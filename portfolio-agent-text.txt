DADOS DO PROJETO

Nome do projeto: LançaEnsaio
Descrição curta: App mobile para registro padronizado de ensaios musicais — versão web demo testável no navegador, sem backend.
Descrição média: App mobile construído com React Native e Expo que substitui fichas físicas de ensaio por lançamento rápido e rastreável. Esta versão web demo dispensa backend, simulando todo o fluxo de configuração, lançamento, comprovante e alerta diretamente no navegador com dados mockados e persistência local. Deploy estático na Vercel com SPA rewrite.
Stack: TypeScript, React Native, Expo, Supabase, AsyncStorage, Vercel
Status: Em produção / Publicado
URL da demo: https://lancaensaio.vercel.app
URL do repositório: https://github.com/BarujaFe1/LancaEnsaio
Categoria: Mobile Web / Demo

Bullets de destaque (4 itens):
- Substituiu fichas físicas de ensaio que se perdiam ou atrasavam por fluxo digital rastreável
- Adaptado de APK Android para web estática sem reescrever (~95% de código compartilhado)
- Modo demo autossuficiente com dados mockados, persistência local (AsyncStorage) e comprovante
- Publicado na Vercel com build customizado (expo export --platform web) e rewrite SPA

Tags: TypeScript, React Native, Expo, Supabase, Vercel
